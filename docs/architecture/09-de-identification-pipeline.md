# 09. De-Identification Pipeline

Part of the [Technical Reference](../TRD.md).

**Status: `Built`**, implemented 13/08/26 (issue #9). This section specified the detection, tokenisation and vault mechanics; `backend/src/deid/` now implements all of them.

## Detector Inventory

| Detector      | Label     | Matches                                                               | Approach                                                                                                                                                                                                                               |
| ------------- | --------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Person Name   | `PATIENT` | The patient's name and any other named individual (family, caregiver) | Pattern-based: capitalised word sequences adjacent to a name cue, honorifics (`Mr`, `Mrs`, `Puan`, `Encik`, `Dr`), Malaysian patronymics (`bin`, `binti`, `a/l`, `a/p`), or immediately after "my name is" / "patient's name is"      |
| NRIC          | `NRIC`    | Malaysian NRIC, `YYMMDD-PB-###G`                                      | Regex on the 12-digit hyphenated format                                                                                                                                                                                                |
| Phone         | `PHONE`   | Malaysian mobile/landline numbers                                     | Regex on `01X-XXXXXXX` / `0X-XXXXXXXX`, with or without country code                                                                                                                                                                   |
| Address       | `ADDRESS` | Postal address fragments                                              | Regex/keyword: a 5-digit postcode co-located with a street-type keyword (`Jalan`, `Lorong`, `Taman`)                                                                                                                                   |
| Date Of Birth | `DOB`     | Explicit birth dates                                                  | Date pattern co-located with a DOB cue ("born on", "DOB", "d.o.b."), distinguished from other clinical dates in the transcript                                                                                                        |
| Record Number | `MRN`     | Medical/registration record numbers                                   | Alphanumeric pattern co-located with a record cue ("MRN", "IC no", "registration no")                                                                                                                                                  |
| Email         | `EMAIL`   | Email addresses                                                       | Standard email regex                                                                                                                                                                                                                   |
| Script        | `SCRIPT`  | Any run of Bengali, Arabic (Urdu) or Devanagari script (#391)         | Every other detector reads Latin script only, so a whole run in one of these becomes one token at the gate. Chinese and Tamil are deliberately excluded: ambient capture hints both, and tokenising them would blind the note (§20.12) |

This inventory satisfies Q7/Q8's honest-limitations posture, not a clinical-grade NER system, see the recall note below.

Identifiers read aloud as number words are covered by a further detector under the existing `NRIC`, `PHONE` and `MRN` labels; see Spoken Digit Runs below.

## Detector Shape: `pattern + score + context`

Detectors are specified as `{ pattern, baseScore, contextWords }` rather than as flat boolean regex, matching Microsoft Presidio's `PatternRecognizer` contract. A low-confidence pattern match is **promoted** when a context word appears nearby, `IC`, `no. kad pengenalan`, `pesakit`, `patient`, `MyKad`, and demoted otherwise. This is the industry-standard shape and is citable as such, which matters for a component whose recall cannot be guaranteed.

Two additions raise precision and recall respectively, at low cost:

- **NRIC structural validation.** Layer a date-of-birth validity check and a place-of-birth state-code check on top of the `YYMMDD-PB-###G` shape match. **MyKad has no checksum**, so this is the only structural check that exists. Copy the state-code table from the MIT-licensed `mykad` package rather than adding a dependency. Cuts false positives at zero recall cost.
- **Name gazetteer.** A deny-list of Malay, Chinese, Indian, Pakistani and Bangladeshi given names plus honorifics, applied as a second recall pass for names carrying no particle or honorific cue. This is the **only** measure available in this window that raises name recall without a model. A known given name takes up to three capitalised neighbours on each side into its token, counted along the whole capitalised run, so a name of up to four words is covered wherever the run starts (#416). A word with an internal capital (`MacDonald`, `O'Brien`) or a one-letter initial still breaks the run, and the elements past it are not reached, as before. The cost is up to seven words of a Title-Cased header where fixed four-word pieces cost four; an unbounded reach swallows whole symptom headers (#178). Where spans overlap, any stretch of the losing span outside every winner, at its start, middle or end, stays a match of its own (#183, #416).
- **Name stopwords.** `NAME_STOPWORDS` holds words shaped like names that are not, so the gazetteer's adjacency rules do not take them into a name span. Every drug the medication lexicon spells is derived into it rather than copied (#317), so a newly listed drug is never tokenised as part of a patient's name.
- **Names in Chinese and Tamil script** (#418). Read only after a cue, because a surname list on its own would tokenise ordinary words (黄, 白 and 高 are also "yellow", "white" and "tall"). The cue lists sit in `gazetteer.ts` beside the Latin introducers; §20.12 lists them and what still passes.

## Why Not Presidio Or An Off-The-Shelf Library

Recorded as a decision with evidence rather than left as silence, because de-identification is the component a reviewer will probe hardest:

| Option                             | Why It Was Rejected                                                                                                                                                                                                                                                                                                       |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Microsoft Presidio**             | Python-only (the maintainer's answer for other runtimes is Docker + REST), which would reintroduce a Python sidecar into a TypeScript stack. Ships `SG_NRIC_FIN` but **no MyKad recognizer**. English-only by default, and its `PERSON` path is documented to perform worst on non-Western names, precisely this corpus. |
| **JS de-identification libraries** | Every one surveyed is a US-centric regex engine (HIPAA's 18 identifiers) with zero Malaysian coverage. Nothing to adopt.                                                                                                                                                                                                  |
| **In-process ML NER**              | GLiNER multi-PII ONNX is ~349 MB int8; the JS runner is a small, stale repo pinned to an old transformers.js. Not viable in this window, and it would not fix Malay-name recall, see below.                                                                                                                              |

**Named future work, with costs**, so the weakest component reads as deliberate rather than unexamined: Presidio in Docker, in-region, as a second pass; GLiNER multi-PII ONNX in-process; a fine-tuned Malaysian de-identification NER seeded from `obi/deid_roberta_i2b2` (MIT, no ONNX shipped).

## Token Format

`[LABEL_N]`, matching the format already fixed in `AGENTS.md` (`[PATIENT_1]`, `[NRIC_1]`). `N` increments per unique value encountered within one request: a second distinct name becomes `[PATIENT_2]`; every repeat of an already-seen value maps to the token already minted for it, so the model sees one consistent handle per person across the whole transcript.

## Vault Lifecycle

- Created once per analyse request, alongside the tokenised text, never a module-level singleton, never attached to a `Consultation` row.
- Populated during detection: `TokenVault.entries` maps each minted token to the original span (§5).
- Consumed exactly once, on the return path, after the LLM response has passed schema validation (§6), `vault.rehydrate()` is called on every string field in the response payload (SOAP note fields, gap `question`/`rationale`, red-flag `label`/`evidence`, suggestion `text`) before the analysis is persisted or shown, because the model may echo a token back verbatim.
- Never serialised: not written to `Consultation.transcript`/`analysis` (§4), not logged, discarded when the request handler returns.

## Fail-Closed Semantics

The de-identification function is specified to throw, not return a partial result, if any detector step fails internally, a caller must never fall back to sending original text. `.env.example`'s own comment states the intent: "fail-closed: when true, `LLMClient` refuses any payload that did not pass through the de-identification gate." Whether that refusal is actually wired into `OpenAICompatibleClient` is the separate, already-recorded gap in §7, referenced here, not restated.

## Audit Surface

Each analyse run writes one `consultation.analysis_completed` `AuditEvent` (§15) with `metadata: { detected: string[] }`, the detector labels that fired (e.g. `["PATIENT","NRIC"]`), never the matched values, per the `AuditEvent.metadata` contract already recorded in §4.

## Recall Limitation

Stated plainly in `docs/PRD.md` §12: these detectors are pattern-based and may miss an identifier, particularly an unmarked name with no adjacent honorific, patronymic, or context cue. **An ML NER would miss it too**, and the published evidence says it would miss it disproportionately for Malay names, so this is a limitation of the problem, not only of the chosen approach. That is why raw transcripts are still treated as sensitive at rest (Q9, §4), and the mitigations that do exist are named rather than implied: the outbound payload is reviewable, the vault is request-scoped, and `LLMClient` is the sole egress point.

## Spoken Digit Runs

**Status: `Built`** (#435). `detectSpokenNumbers` in `backend/src/deid/detectors.ts` is in `DETECTORS`, so `assertNoIdentifiers` re-runs it at egress. The scanner is `backend/src/deid/spoken-numbers.ts` (`scanSpokenNumbers`, `spokenDigitRuns`).

### Why It Exists

- Speech-to-text returns an identifier as words, not digits: the synthetic line "Nombor kad pengenalan saya 900412086543." (fixture `urti-malay-red-flag`) was read by two TTS voices and transcribed by batch `scribe_v2` 32 times, never once as digits, in 28 distinct readings (measured 15/10/26).
- Every digit detector is blind to that, which is the §20.13 risk "Spelled-out numbers are a de-identification risk".
- No new `DetectorLabel`: it mints `NRIC`, `PHONE` or `MRN`, so the logger allowlist is unchanged.

### Scanner

| Aspect       | Behaviour                                                                                                                                                                                                                                                                                                                        |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tables       | Its own. English singles (zero, oh, o, nought, one to nine), Malay (kosong, sifar, satu to sembilan, lapan, delapan), Mandarin (零 〇 一 幺 to 九, one unit per character, no spaces needed)                                                                                                                                     |
| Multi-digit  | English ten to nineteen, twenty to ninety, and tens plus single as one compound ("thirty-eight" is 38). Malay sepuluh, sebelas, X belas, X puluh, X puluh Y                                                                                                                                                                      |
| Repeats      | double or triple plus a single. "sama" directly after a single repeats it                                                                                                                                                                                                                                                        |
| ASCII digits | Outside a cue, a digit group is one unit whatever its length, so "38, 39, 38" is three readings; under a cue each ASCII digit counts as a single. A group written against a letter (SpO2, B12) is no unit. A run holding no number word is never reported, so text whose numbers are all digits passes the gate byte-identically |
| Breakers     | point, titik, hundred, ratus, over, kali; 两 十 百 千 万 点; `? ! ;` and full-width forms; newline; the vault placeholder                                                                                                                                                                                                        |
| Separators   | At most one of `, - – / :` (and full-width `，：、`) per gap. A hesitation (uh, um, umm, er, erm, ah, eh) is part of a gap, which may then hold a punctuation mark either side of it. After 9 digits, a separator ends the reading when one number word and an ordinary word follow (", two tablets")                            |
| Independence | Deliberately does not import `SPOKEN_NUMERALS` from `medications/vocabulary.ts`, so a dose-parser change cannot move the PHI boundary                                                                                                                                                                                            |
| Cost         | Linear: one tokenising regex that cannot backtrack, and a bounded clause scan                                                                                                                                                                                                                                                    |

### Run Rule

| Digits    | Requirement                                                                                                                                                                                                                                            | Label                                                                                               | Outcome                                          |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 9 or more | At least 4 single-digit units, more singles than two-digit number words, at least 2 number words                                                                                                                                                       | `NRIC` if 12 digits and structurally valid, `PHONE` if the digits match `PHONE_PATTERN`, else `MRN` | Always tokenised (score 0.8)                     |
| 3 to 8    | Every unit a single digit, directly after an MRN cue (only `[:\s.#-]*` between)                                                                                                                                                                        | `MRN`                                                                                               | Tokenised (0.8)                                  |
| 6 or more | At least 4 single units, an identity or phone cue earlier in the run's own sentence or in the question it answers; 6 to 8 must not be a +/-1 progression and needs 2 number words; 9 or more lands here when it has as many two-digit words as singles | `NRIC` for an identity cue, else `PHONE`                                                            | Tokenised (0.3 base plus the 0.35 context boost) |
| Other     |                                                                                                                                                                                                                                                        |                                                                                                     | Untouched                                        |

### Cue-Anchored Rule

- **Anchor.** An identity cue, which labels the reading `NRIC`, or a phone cue, which labels it `PHONE`. Identity cues: ic, icnya, i/c, k/p, nric, mykad, mykadnya, kad pengenalan, kad pengenalannya, identity. Never the clinical-setting words clinic, klinik, medical, physician, pesakit. These are also the only NRIC cues a spoken run is scored on. Its phone cues are the nouns phone, telephone, handphone, hp, mobile, telefon, and "number" only as someone's: my number, your number, contact number, number saya, nombor saya, nombor awak, nombor anda.
- **Fillers.** Up to three of: number, no, nombor, card, kad, is, was, it's, its, my, saya, dia, ialah, adalah, ni, ini, punya. The next word must be a number unit.
- **Clause end.** Whichever comes first: a breaker; `. ? ! ;` or full-width forms; a newline or vault placeholder; any other punctuation; a separator not directly followed by a number unit it joins; an opener (and, but, so, then, also, dan, tapi, tetapi, lepas, lagi, sebab, kerana, juga); a word another detector reads as a cue (`CLAUSE_STOPS`); an ordinary word once 12 digits have been read, or a separator before a dose as in the run rule; 16 words after the anchor. A hesitation ("uh") short of 12 digits is a fragment, not an end.
- **Span.** If the clause ends on a number unit, the whole clause from the anchor is tokenised, fragments included. Otherwise only the unbroken run at the anchor.
- **Label and score.** `NRIC`, 0.85, when the span holds at least 2 number words and at least 3 units, or 2 units with garbled fragments between them.
- **Why bounded.** Running past a comma, opener or sentence end into ordinary words is the #174 failure (masking "500 mg").
- **Why the cue stops.** A cue word taken into the token is lost to its own detector: "My IC is nine she lives two." hid "lives" from the address said after it, found in review.

### Deviations From The Approved Plan

- The MRN-direct band runs to 8 digits, not 5. "MRN" names neither an IC nor a phone, so a six-digit record number read after it would otherwise pass.
- "no." with its full stop is accepted as a filler ("IC no. nine ..."), because it abbreviates rather than ends a sentence.
- Punctuation other than the listed separators ends the cued clause, which is more conservative than the plan's list.
- Found in two rounds of clinical-safety and PHI review, each pinned in the #435 block with the reviewer's input:
  - ASCII groups are one unit outside a cue, and a digit against a letter is none: "Fever 38, 39, 38, 37, 38, two days" and "SpO2 nine one, nine zero, eight nine, eight eight" were tokenised. Under a cue each ASCII digit counts again, as the plan has it: "My IC is 90041208654 three" passed.
  - Spoken runs score on identity words and phone nouns only, earlier in their own sentence or the question they answer, never 48 characters either way as `scoreWith` reads: "Pulse one two zero, one one eight, at the clinic", "Call us if the oximeter shows nine two, nine one, nine zero" and "Thanks for the IC. Temperature three eight five, three nine one" were tokenised. "number" counts only as someone's, so "My number is" and "what's your number?" still cue.
  - A 9-digit run tokenises with no cue only when its singles outnumber its two-digit words: "Thirty-nine five, thirty-nine eight, thirty-nine one, thirty-eight eight" pairs one of each per reading and was tokenised, while a phone read with a pair or two has to be caught. - Two number words at least, short of a cued reading of 9 digits, and a reading ends at a separator before a dose: "RN 4521 two tablets" and "IC 900412-08-6543, two tablets" lost their dose word.
  - The cued clause stops at other detectors' cue words, so "My IC is nine she lives two." no longer hides "lives" from the address after it, and at an ordinary word once 12 digits are read, so "... four three pulse one oh two" keeps the pulse. Phone cues anchor a clause too, so "My number is zero one ninety-three seventy-two..." is caught.
  - The cued floor is 3 units, or 2 across fragments, so "IC two three days of fever" keeps its duration and reading 21 still tokenises.

| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Counting aloud                          | "one, two, ... nine", with or without "ten", is always tokenised. The 9-digit rule has no progression exemption because the corpus phone read aloud ("zero one two three four five six seven eight nine") is itself a progression                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Phonetic-fragment readings              | Still pass (readings 23 to 28)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Tamil number words                      | Still pass. There is no Tamil table, and `SCRIPT` deliberately does not read Tamil                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Uncued pairs                            | A reading of 9 digits or more with no cue passes when it has as many two-digit words as singles, as with "eighty-five, oh five, twenty-three, fourteen, fifty-six, seventy-seven". After "My IC is" or a phone cue, the cued clause catches it. In answer to a question naming a cue only the cued band can, which wants four single digits, so a reading almost all in pairs passes: "Doctor: what's your number?\nPatient: zero one ninety-three seventy-two eighty-four sixty-five"                                                                                                                                                                                                                                                                                                       |
| Mandarin cue                            | 身份证 is not an anchor, and a Latin cue written directly against Han characters ("我的IC是") does not match, so a Mandarin reading is caught only by the run rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Date of birth as words                  | Not covered by `DOB` (which needs digits). Caught only if it happens to meet a run rule                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Long cued clause                        | Short of 12 digits, it takes up to 16 words of fragments when it ends on a number unit, so clinical words said in the same unpunctuated clause before a final number word go into the token. A stop word inside a reading ends it early instead: "IC saya ... lapan nama enam lima empat tiga" leaves four digits in clear                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Readings said digit by digit            | Any series of nine digits or more said mostly digit by digit in one breath tokenises with no cue, vital-sign logs included: "Sats ninety-two, nine one, nine zero, eighty-nine, eighty-eight", "Temp three eight five, three eight nine, three nine one, thirty-eight", "Pulse one one two, one oh eight, one oh four", "BP one three five eh eight five, one three two eh eight two", "one-one-one, one-zero-one, zero-zero-one", a taper "four four four three three three...", "三八五，三九，三八二，三七八". `vital-signs-concern` carries no numeric cutoff, so a spoken desaturation read this way reaches no rule and the model reads a token. Values come back on rehydration. A veto on a vital-sign word before the run would close it at some PHI recall: an open owner decision |
| A cue in the question, or "your number" | A run answering a question that names a cue takes its label whatever it is: "Do you have your IC?" before "Temperature three eight five, three nine one" tokenises it as `NRIC`, and "the phone app" before an oximeter reading as `PHONE`. This is what lets "what's your number?" cue the number read back                                                                                                                                                                                                                                                                                                                                                                                          |
| A corrected tail                        | "..., sorry, six five four three" after a whole reading is a new reading with no cue, and passes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
